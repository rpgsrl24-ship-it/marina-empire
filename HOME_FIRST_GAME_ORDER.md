# Marina Empire — Ordine di gioco Home-first

## Obiettivo
La Home diventa la plancia principale. Il giocatore deve poter avviare quasi tutte le azioni senza navigare tra schermate separate. Le pagine esistenti restano come dettaglio avanzato.

## Struttura operativa definitiva

1. MARINA LIVE
- marina attuale 3D
- traffico, VHF, richieste, emergenze
- cambio marina e ingresso nella marina

2. VIAGGIO
- missione consigliata
- missioni disponibili
- pianifica rotta
- partenza
- stato viaggio / arrivo

3. YACHT
- yacht attivo
- cambia yacht
- carburante
- fai il pieno
- stato yacht
- manutenzione

4. IMPERO
- marine possedute
- attività nautiche
- charter automatici
- economia
- percorso carriera

5. MERCATO
- marketplace
- acquisto/vendita yacht
- water toys e accessori
- crediti Marina Empire

6. COMMUNITY
- chat generale
- chat marina attuale
- giocatori online
- classifica

7. COMANDANTE
- profilo
- account
- salvataggio
- uscita

8. QUARTIER GENERALE
- Isola delle Rose
- base RPG Yacht
- mai acquistabile dai giocatori

## Pagine esistenti riutilizzate
- home → plancia operativa
- map → pianificazione rotta / navigazione
- missions → elenco missioni completo
- fleet → gestione flotta dettagliata
- marinas → rete marine / ormeggi / proprietà
- office → economia / attività / community
- marketplace → mercato nautico
- credits → acquisto crediti
- profile → comandante / account / salvataggi
- headquarters → Isola delle Rose

## Regola UX
Ogni funzione principale deve avere:
1. stato sintetico visibile in Home
2. azione principale eseguibile dalla Home
3. pulsante “DETTAGLI” verso la pagina completa solo quando serve

## Ordine di sviluppo dopo la Home
P0 — collegamenti Home
- Missioni
- Rotta/Partenza
- Flotta
- Rifornimento
- Manutenzione

P1 — gestione impero
- Marine
- Attività nautiche
- Charter automatici
- Marketplace
- Crediti

P2 — mondo vivo
- Community
- Classifica
- Eventi / emergenze / richieste dinamiche
- VHF contestuale

P3 — rifinitura
- Profilo / Account / Esci
- Isola delle Rose
- onboarding nuovo giocatore
- pulizia menu duplicati

## Principio finale
Il giocatore apre Marina Empire e dalla Home deve capire subito:
- dove si trova
- quale yacht sta usando
- quanto carburante e stato ha
- cosa può fare adesso
- quanto può guadagnare
- qual è il prossimo obiettivo
- cosa sta succedendo nel mondo nautico
